# Experience constitution

Status: recovered principles consolidated for implementation. This is not a verbatim restoration of every Phase 3 subphase.

## Hierarchy and agency

Content takes priority over interaction effects; interaction takes priority over atmosphere. Semantic HTML carries meaning and controls. WebGL supplies the spatial presentation.

Critical content stays stable and readable. Navigation retains discoverable section access and return paths. The camera guides without taking agency away. Scroll is an input to narrative progression; it should not make orientation or access dependent on completing a spectacle.

## Interaction

Recovered response sequence: detection → acknowledgment → local response → state change → environmental consequence → settling.

Causal order: visitor → target → local structure → environment. The target responds before the surrounding world. Proximity does not activate an action. Hover discovers; click / tap / keyboard activation commits.

The native cursor remains primary. An optional contextual intention field may influence the world without a giant replacement cursor. Touch does not need to imitate hover; keyboard focus provides equivalent discovery and activation paths.

Interaction memory is proportional and decays. Repeated input updates a response instead of blindly restarting every animation. Completion and failure must remain understandable.

## Motion and time

Use a dominant event, one or two supporting responses, and low-cost ambient life. Higher-priority events quiet lower-priority movement. Ambient motion is subtle, irregular, desynchronised, and periodically rests.

Responses have an identifiable cause, acknowledgment, proportional change, and settling. Large transformations are exceptional. The entity should not continuously perform an idle animation just to prove it is alive.

Motion coordination may allow, reduce, defer, merge, or interrupt an event. Exact implementation and timing values remain open. Avoid competing writers for the same visual property.

## Intelligent interaction and adaptation

Recovered conceptual pipeline: perception → interpretation → intent / confidence → contextual response.

Explicit user intent outranks inference. Low confidence limits the authority of an inferred response. Changes should be minimal, purposeful, interruptible where appropriate, reversible, and able to settle.

Adaptation is bounded across time and coordinated across systems. Do not let inferred engagement block content, change the visitor's objective, or create unpredictable navigation. Exact signals, thresholds, retention, and state schemas are open decisions.

“Intelligent” describes behavior in this plan; it is not evidence of an approved AI model integration, analytics pipeline, or backend.

## Spatial and interface principles

True 3D handles world existence; DOM / 2D handles communication. Preserve depth and orientation while keeping text usable. Space is the default visual container; use explicit panels when they improve comprehension.

Recovered interface states: Ambient, Aware, Active, Focused. Responsive concepts: Expansive, Compact, Condensed, Constrained. These are conceptual categories, not implemented state machines or finalized breakpoints.

## Accessibility and resilience

Pointer, touch, keyboard, assistive technology, and reduced-motion users retain meaningful access to content and actions. Reduced motion preserves meaning, hierarchy, and feedback while changing presentation.

Quality reductions protect content, controls, orientation, and coherent identity before decorative fidelity. Mobile needs deliberate recomposition rather than a scaled desktop canvas.

## Review prompts

- Can users read and navigate without understanding the visual metaphor?
- Does each effect have a cause, priority, and end state?
- Does the target respond before the environment?
- Does the entity retain fragmentation and negative space?
- Are meaningful actions available across supported input methods?
- Is performance claimed from measurements rather than appearance?
